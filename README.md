## Run

Extract the whole package and open `index.html` in a current desktop browser, keeping the assets folder and all JavaScript files together. The new **Rooftop Reservoir** level opens by default. The three Week 2 practice rooms are still selectable. No build, engine installation or network connection is needed.

If your browser restricts local files, run `python -m http.server 8000` in this directory and visit `http://localhost:8000`. This optional server requires Python.

## Controls

- Arrow keys / WASD: move one tile.
- Space: wait one turn.
- E: start or finish recording, up to eight commands.
- Enter: activate the pump, sign or terminal on your current tile.
- R / Backspace / Reset attempt: return to your current session checkpoint.
- Restart whole level: clear all pumps, checkpoints, turns and reset count.
- Effects and Music buttons: separate opt-in audio controls.

Movement and action buttons also work with pointer input. Tab navigates buttons and Enter activates the focused control. Keyboard Enter while a button is focused activates that button, so click the board to return focus to gameplay if needed.

## Week 4 level

The Rooftop Reservoir is a 21×11 tile map with three connected stages. Gate 1 leads to pump A, gate 2 leads to pump B and gate 3 leads to the final reservoir. Pumps latch upstream gates, remove the old Echo and establish a checkpoint from which you can create a fresh recording. Gates 2 and 3 require the prior pump to be restored.

Checkpoint progress exists only until a page reload or level switch. Completed-room best scores can persist in browser storage. This distinction is also shown in pump messages. There is no timer or enemy. Walls and closed gates block movement; decorative planters and signs are walkable details.

See `design/LEVEL_BLUEPRINT.md` for the complete design, zero-based object coordinates, solutions, balancing rationale and future human playtest plan. `design/LEVEL_MAP.png` is the annotated map. `design/level4.json` is an exported snapshot of the actual runtime level in `core.js`.

## Exact walkthrough

At start (2,8): E, Right ×2, Up ×2, E. Then Right ×4, Up, Right ×2, Down, Right, Enter. Pump A becomes checkpoint. Nine replay turns.

At A (9,8): E, Right ×2, Up ×5, E. Then Up ×4, Right ×6, Down, Enter. Pump B becomes checkpoint. Eleven more replay turns.

At B (15,5): E, Up ×3, E. Then Right, Up ×2, Right ×3, Up, Enter. The reservoir completes. Seven more replay turns.

The documented route takes 27 replay turns, uses recordings of 4, 7 and 3 commands, and scores 730 with no resets. It is verified, not proven globally shortest. Recording movements are excluded from the replay count. R restores the baseline turn count at the checkpoint and adds a reset penalty.

## Environment and assets

20 editable SVG images and six WAV audio files are integrated. New decorative planters and signs join the Week 3 art. Numbered plates and gates show links. Pumps change floor/planter states and open gates permanently; final completion restores the remaining area. Restoration is a visual state change, not fluid simulation.

The SVGs, synthesized WAVs and generator were prepared with AI assistance. No external art/audio packs or human playtest results are claimed. `tools/make_assets.py` regenerates the 26 runtime assets using Python standard-library code; `assets/manifest.json` records properties. The contact sheet and level map are documentation, not regenerated by that asset script.

Audio starts off. Browser playback may require interacting with a control. Operating-system reduced motion disables movement interpolation, frame cycling, gate flashes and particles. All essential state changes remain visible. Missing images have letter fallbacks; audio errors do not interrupt the puzzle.
